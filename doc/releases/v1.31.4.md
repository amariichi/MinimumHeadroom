# v1.31.4

Require the Node.js November 2026 security releases: 22.23.5, 24.22.3
(recommended), or 26.13.1 and later patches in those supported major lines.
The setup check, package metadata, CI runtime and installation guides now agree.

Existing installations must update their Node runtime separately and restart
Node-based services to load it. Updating the repository alone does not replace
an installed runtime. Python/system SQLite installations are separate and are
not changed by this release.

Validation: the complete Node test suite passes on Node 24.22.3, including
regression tests rejecting earlier patch releases.

[Node.js advisory](https://nodejs.org/en/blog/vulnerability/november-2026-security-releases)
